# Task — Mach 5 impinging-shock / turbulent-boundary-layer interaction (SWBLI)

Solve the steady, 2D supersonic turbulent flow over a flat plate
disturbed by an oblique shock generated by a 10-degree wedge above
the plate, and report scalar metrics describing the shock-induced
separation bubble and the upstream/downstream skin-friction levels.

## Geometry

The configuration follows the NPARC Alliance / DLR Schülein layout as
adopted by the SU2 V&V suite. All dimensions are in metres.

- Lower wall (the plate of interest) is a flat no-slip surface from
  `x = 0` to `x = 0.523` m. The first 10 mm (`x ∈ [-0.01, 0]`) is a
  symmetry / slip wall used to avoid a no-slip / supersonic-inlet
  intersection.
- Upper boundary (the shock generator side) is a flat ramp:
  - `x ∈ [-0.01, 0.023]` is a horizontal slip / inflow-parallel face
    at `y = 0.115` m.
  - From `x = 0.023` m the upper surface deflects downward at
    `θ = 10°` (i.e. a 10-degree wedge), producing a single oblique
    shock that travels down toward the plate.
  - The deflected wedge ends at `x = 0.31844, y = 0.062906` m, then
    becomes horizontal again to `x = 0.523, y = 0.062906` m.
- The oblique shock impinges on the lower plate near `x ≈ 0.34` m;
  shock-induced separation is expected in the band
  `x ∈ [0.32, 0.36]` m.
- Spanwise: 2D (single-cell extruded / empty / wedge).

The geometry, mesh hints, and physical-curve naming are taken from
the canonical GMSH script
`vv-sources/benchmarks/SU2-VandV/rans/swbli/geometry_and_mesh.geo`
(also reproduced on the SU2 V&V site).

## Flow conditions

The free-stream conditions match Schülein (DLR IB 223-96 A 49, 1996;
re-published Schülein 2004 / 2006) and the SU2 V&V configuration
(`MACH_NUMBER=5`, `FREESTREAM_TEMPERATURE=68.3333`,
`FREESTREAM_PRESSURE=4006.88`, `REYNOLDS_LENGTH=0.523`):

| quantity | value |
|---|---|
| free-stream Mach `M_inf` | 5.0 |
| free-stream static temperature `T_inf` | 68.333 K (≡ T0=410 K, M=5, γ=1.4) |
| free-stream static pressure `p_inf` | 4006.88 Pa (≡ p0=21.2 bar, M=5) |
| free-stream velocity `U_inf` | 828.58 m/s |
| unit Reynolds number | 4.0 × 10⁷ m⁻¹ |
| Re based on plate length L=0.523 m | 2.092 × 10⁷ |
| working fluid | air, ideal gas, γ=1.4, R=287.058 J/(kg·K) |
| viscosity model | Sutherland (μ_ref=1.716e-5, T_ref=273.15 K, S=110.4 K) |
| Pr_lam / Pr_turb | 0.72 / 0.90 |
| boundary-layer state | fully turbulent ahead of the interaction |

## Boundary conditions

- **Inlet** (left face, including wedge inflow face): supersonic
  inflow at the free-stream conditions above.
- **Outlet** (right face): supersonic outflow / first-order
  extrapolation.
- **Bottom plate** (`x ∈ [0, 0.523]`, `y = 0`): no-slip, **adiabatic**
  (zero heat flux). This follows the SU2 V&V configuration. The
  underlying Schülein experiment used Tw = 300 K (Tw/T_aw ≈ 0.8); an
  adiabatic-wall computation is the published reference, so use
  adiabatic.
- **Symmetry strip** (`x ∈ [-0.01, 0]`, `y = 0`): symmetry / Euler slip
  wall.
- **Top wedge** (the deflected ramp from `x = 0.023` to
  `x = 0.31844`): no-slip, adiabatic. The boundary layer on the wedge
  is what drives the oblique-shock formation.
- **Top horizontal segments** (upstream of and downstream of the
  ramp): the upstream segment can be modelled as inlet-parallel
  (slip) and the downstream segment as outlet-parallel (slip / first-
  order extrapolation), matching the SU2 V&V `inlet`/`outlet` markers
  on those edges.
- **Spanwise**: 2D / empty / single-cell wedge.

## Required mesh discipline

The interaction is sensitive to wall and shock resolution. The
authoritative SU2 V&V grid family (L1=37k, L2=76k, L3=146k cells)
keeps `y+ < 1` on the plate at the coarsest level, refines the
near-wall layer with a geometric stretching of ~1.1, and clusters
cells around the impinging-shock line `x ≈ 0.34` m. Aim for the same
order of magnitude (~50k–200k cells), wall-normal `y+ < 2`, and
streamwise clustering in `x ∈ [0.32, 0.37]` m.

## Required output

Write `/tmp/agent/result.json`. Each KPI is `{value, source}`; the
verifier re-extracts and compares.

| key | meaning |
|---|---|
| `mesh_cell_count` | total number of cells in your computational mesh |
| `final_residual_U` | last residual of the streamwise momentum equation |
| `cf_upstream` | local skin-friction coefficient `C_f` at `x = 0.320 m`, ahead of the interaction (undisturbed turbulent BL) |
| `cf_min` | minimum (most negative) `C_f` along the plate inside the separation bubble. If the run never separates, report `0`. |
| `x_separation` | streamwise location of the upstream zero-crossing of `C_f` (separation onset). If the run never separates, report `0`. |
| `separation_length` | `x_reattachment − x_separation`, where `x_reattachment` is the downstream zero-crossing of `C_f`. If no separation, report `0`. |
| `cf_post_shock` | local `C_f` at `x = 0.400 m`, well downstream of reattachment, in the recovered turbulent BL |

`C_f = τ_w / (0.5 · ρ_∞ · U_∞²)` where `τ_w` is wall shear stress on
the bottom plate.

### Source kinds

- `file_extract` — value lives in a file you produced. Provide
  absolute `path` and an `extract` shell pipeline of allowed binaries
  (head/tail/awk/sed/grep/cut/tr/sort/uniq/wc/cat/jq).
- `sim_run_stdout` — value in captured `sim run` stdout; provide
  `run_id` and `extract`.
- `sim_run_kpi` — value in a sim-run's `parsed_output` dict; provide
  `run_id` and `field`.

## Analytical-shortcut notice

There is no closed-form solution for shock-induced turbulent
separation length, peak interaction skin-friction, or recovery `C_f`
downstream of reattachment. Free-interaction theory gives a ballpark
for separation onset pressure but cannot predict the size of the
bubble or the full `C_f(x)` distribution at finite Reynolds number
with realistic turbulence-model behaviour. A real solver run is
required: `T_good` on `cf_min`, `separation_length`, and
`cf_post_shock` is wide enough to absorb SA-vs-SST variation but
narrow enough that hard-coded constants will fail.
